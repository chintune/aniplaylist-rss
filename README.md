## 🎶 What it does

AniPlaylist RSS turns AniPlaylist seasonal music listings into clean RSS feeds and a simple web interface, with direct links to supported music platforms.

## 📅 Seasons

The project tracks anime music by season, including:

- **Fall 2026**
- **Winter 2027**
- **Spring 2027**
- **Summer 2027**
- **Fall 2027**

## 🎤 Music coverage

The feeds focus on anime-related releases such as:

- Opening themes
- Ending themes
- Insert songs
- OST / soundtrack releases
- Other theme and anime music entries exposed by AniPlaylist

## 🔗 Music platforms

Where a matching release is available, entries can include:

**Spotify · Apple Music**

## 🔄 Updates

Source data is refreshed **every 30 minutes** and the generated RSS/site data is published when changes are detected.

## 📡 RSS

Seasonal RSS feeds are published from the website under the `/rss/` path.

🌐 **Website:** https://chintune.github.io/aniplaylist-rss/
